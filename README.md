# Bharat Sinha | Data Analyst Portfolio

Cinematic, SEO-ready portfolio for GitHub Pages with a built-in CMS. No framework, no third-party scripts.

## What is in this repo
| File / folder | Purpose |
|---|---|
| `index.html` | The site (template; the build fills it from `content.json`) |
| `content.json` | ALL editable content: text, projects, skills, hallway numbers, FAQ, links |
| `admin.html` | The CMS (live preview, media, history, SEO, deploy status) |
| `404.html` | Dark 404 page |
| `scripts/build.py` | Builds the static site: case-study pages, sitemap, robots, meta, JSON-LD |
| `.github/workflows/pages.yml` | Builds and deploys to GitHub Pages on every push |
| `media/` | Hero films: `reel-wide` (2.39:1, desktop) and `reel-tall` (9:16, phones), each as MP4 + WebM, plus posters |
| `images/` | Project dashboard screenshots (WebP 960px / 1600px + OG JPEG) |
| `manifest.webmanifest`, `favicon.ico`, `favicon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `og-image.png` | App icons and social preview |
| `robots.txt`, `sitemap.xml` | Crawling (regenerated by the build) |
| `Bharat Sinha CV.pdf` | Downloadable CV (replace it from the CMS, Media tab) |
| `SEO-CHECKLIST.md` | Off-page SEO steps (what really moves rankings) |

## One-time setup
1. Create the repo (for example `bharat-sinha.github.io`) and upload EVERY file and folder, keeping the structure.
   If your browser skips the hidden `.github` folder, create `.github/workflows/pages.yml` by hand:
   Add file, Create new file, type the full path, paste the content.
2. Settings, Pages, Build and deployment, Source: **GitHub Actions**.
3. Actions tab, "Build and deploy portfolio", **Run workflow** once. Wait for the green tick.
4. The site is live at `https://<username>.github.io/`. Admin: `.../admin.html`.

## Design (single dark theme)
- Chiaroscuro: pure black with localized amber glow; bento blocks with a pointer-tracked glow and animated film grain.
- 2.39:1 letterbox bars that open on load, shrink while scrolling, and re-frame on portrait phones.
- Floating bottom dock for navigation (auto-hides while scrolling down, always reachable).
- Kinetic type: letter-by-letter blur-in for the hero, mask wipes for section titles.
- Hallway: key numbers fly past the camera on a Z-axis dolly (desktop); plain opacity fades on phones.
- Pinned horizontal project scene, work index with a cursor-following image preview (desktop) and a scroll-triggered reveal (touch).
- Shared-element page transitions: the project thumbnail scales up into the case-study hero (View Transitions API).
- Desktop hero: adaptive film (wide on desktop, vertical on phones, poster only on data-saver) plus a cursor-reactive WebGL smoke layer.
- Momentum scrolling on desktop mouse/trackpad (own code, no library); touch devices keep native scrolling.
- Respects `prefers-reduced-motion` (no motion effects, no autoplay, static hallway list) and works without JavaScript.

## Everyday use (the CMS)
1. Open `https://<username>.github.io/admin.html`.
2. Enter `username/repo`, branch `main` and a fine-grained token (only this repo).
   Permissions: **Contents: Read and write** (required), **Actions: Read-only** (optional, shows Deploying / Live).
3. Edit anything, then **Publish** (or Ctrl+S). Everything is saved in ONE commit; the workflow rebuilds in 1-2 minutes.

What you can manage: Profile, Projects (with screenshots), Skill levels, **Hallway** numbers, Skill tags, Experience, Education, FAQ, Media (images, CV), SEO, plus Overview health checks, live preview, History/restore, Undo/Redo, drafts, Export/Import.

## Project screenshots
Upload a screenshot in the Projects tab: two sizes are created automatically (960px and 1600px). Fill "Image description" (alt text).

## SEO (automatic)
Every publish rebuilds the home page, one case-study page per project, `sitemap.xml`, `robots.txt`, titles, descriptions and JSON-LD.
The site URL is detected from the repo; a `CNAME` file (custom domain) wins. Search Console / Bing codes: CMS, Profile tab.
Read `SEO-CHECKLIST.md` for the steps outside the site.

## Replacing the hero films (optional)
`media/` holds procedurally generated loops (amber smoke, light shaft, dust). Replace them with your own footage,
keeping the names `reel-wide.mp4/.webm` (about 2.39:1, 1920x804) and `reel-tall.mp4/.webm` (9:16, 720x1280), each under ~2 MB.

## Notes
- Never upload `_site/` (generated; listed in `.gitignore`).
- Local build test: `python scripts/build.py`, then serve `_site/` (for example `python -m http.server`) and open it.
- The contact form uses FormSubmit.co (free). On the first message it emails you an activation link.
