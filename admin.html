Portfolio CMS

Connect once, then edit every part of the site. Publishing saves everything to GitHub in one commit, and the live site updates in about 1-2 minutes.

How to get a token (2 minutes)
  1. GitHub, then Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, then Generate new token.
  2. Expiration: 90 days. Repository access: Only select repositories, choose this portfolio repo.
  3. Repository permissions: Contents = Read and write (required). Optional: Actions = Read-only to see "Deploying / Live" status.
  4. Generate, copy the token and paste it above.
